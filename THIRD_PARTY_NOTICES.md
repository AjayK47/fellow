# Third-party notices

Toda's application code is released under MIT. Runtime Python and JavaScript
dependencies retain their own licenses as declared by their distributions.

Built-in skill manifests are the authoritative per-package provenance record.
Most are original Toda procedures released under MIT. Some procedures are
adapted from or inspired by other open-source projects:

- Hermes Agent-inspired original procedures are marked `inspired_by:
  hermes-agent`. Procedures adapted from Apache-2.0 material retain
  `license: Apache-2.0` and an `adapted_from` origin.
- AntV Infographic integration and procedure are MIT-licensed and identify the
  upstream source in their manifest.
- The SVG procedure identifies its upstream inspiration and is distributed
  under MIT.

No repository under the private `harnesses/` reference directory is part of
the Toda Community distribution or container build context.

Distributors are responsible for retaining dependency license notices when
redistributing binaries or containers.
