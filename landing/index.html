Built for an organization, not an individual inbox.

01

Conversation before Tasks

“Hi” is a conversation. Research, documents, approvals, waiting, and multi-stage outcomes become durable work only when they need to.

02

Memory with boundaries

Public does not mean universal. Toda re-authorizes memory, Task history, citations, and artifacts for the current person and destination.

03

Delegation with a reason

The main agent handles ordinary work. It creates a child only for useful parallelism, context isolation, specialist tools, or independent long-running execution.

04

Evidence stays attached

Graph relationships connect Tasks, people, projects, artifacts, Skills, and sources without requiring a separate graph database.

05

One process owns coordination

Slack, API, workers, recovery, and proactive attention share one daemon and one SQLite coordination boundary.
