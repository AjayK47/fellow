# Support

Toda Community is maintained in public and released without an SLA.

- Use GitHub Discussions for setup questions, architecture questions, and
  ideas that are not yet actionable issues.
- Use the bug template for reproducible defects.
- Use the feature template for scoped product proposals.
- Use private vulnerability reporting for security concerns.

Before requesting help, run `python scripts/verify_release.py`, include your
Toda version, operating system, installation method, relevant non-secret
configuration, and sanitized logs. Never paste credentials, company messages,
database files, or connector payloads into a public report.
